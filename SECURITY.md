| Version | Supported          |

---

## Reporting a Vulnerability

We take the security of SmoothFlow and our users seriously. If you discover a security vulnerability, please do NOT file a public issue.

Instead, please send an email to **[earondemands@gmail.com]** with:
- Description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Potential impact.

You will receive a response within 48 hours acknowledging receipt. Valid vulnerabilities will be addressed in a rapid hotfix release.
